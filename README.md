It is a html script created by Claude to track and manage stocks which appear daily in different scans. For details please go through the user manual. 
What's inside the manual:
What Is This Tool — description, what it solves, full list of capabilities
How to Access — desktop local file, GitHub Pages setup, mobile home screen
Daily Workflow — step-by-step scan logging, reading the leaderboard
Filters & Controls — Min Hits filter, sort modes, heatmap explained
Syncing Between Devices — export/import JSON, Merge vs Replace explained, JSON file structure with a colour-coded example
Exporting to Excel — CSV columns explained
How to Improve It — adding scan types, changing the window, adding volume/price data, connecting to Google Sheets, CSV upload — all with specific instructions
Quick Reference — tab summary table, scan type colour code table
The "How to Improve" section is written so you or anyone else can either do it directly or just paste the app into Claude and ask for the specific change.
